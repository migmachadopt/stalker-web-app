# 📺 Stalker IPTV Web Player - VERSÃO FINAL

✨ Com **Auto-Discovery** de Endpoints!

## 🎯 Funcionamento

Inseres apenas: `http://ripana.top`
O backend descobre automaticamente: `/portal.php` ou `/stalker_portal/server/load.php`

## 🚀 Instalação Rápida

```bash
# Backend
cd backend && npm install && npm start

# Frontend (nova janela)
cd frontend && python3 -m http.server 8000
```

Abre: http://localhost:8000

## 📝 Como Usar

1. Insere **Base URL**: `http://ripana.top` (SÓ o host!)
2. Insere **MAC**: `00:1A:79:XX:XX:XX`
3. Clica "Connect"
4. Backend auto-descobre o endpoint correto ✨
